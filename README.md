# Mahesh Gadakh — Personal Portfolio

Production-ready, cinematic single-page portfolio for **Mahesh Gadakh**, Customer Data Platform Specialist, Marketing Technology Consultant, and Data Engineer.

## Tech Stack

- **Framework:** Astro.js (v5, static output)
- **Language:** TypeScript
- **Styling:** Vanilla CSS with custom properties
- **Animations:** GSAP & ScrollTrigger
- **Visuals:** Vector SVG architecture graphs & optimized WebP monochrome portrait cutout
- **Deployment:** Optimized for static hosting (Cloudflare Pages, Vercel, Netlify)

## Commands

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Starts the local dev server at `http://localhost:4321`.

### 3. Production Build
```bash
npm run build
```
Generates a static production bundle in `dist/`.

### 4. Local Production Preview
```bash
npm run preview
```

## Cloudflare Pages Deployment

1. Connect your GitHub repository to Cloudflare Pages.
2. Build settings:
   - **Framework preset:** Astro
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
